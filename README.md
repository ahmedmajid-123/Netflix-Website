# 🎬 Netflix Landing Page Clone

A responsive landing page clone of Netflix built with **HTML5** and **CSS3**. This project replicates the user interface of Netflix, including modern styling, hover effects, and full responsiveness across different screen sizes (mobile, tablet, and desktop).

---

## 🚀 Features

* **Hero Section:** Custom background overlay with dynamic text sizing and email CTA.
* **Responsive Layout:** Adaptive design using CSS Media Queries for mobile and desktop screens.
* **Feature Sections:** Highlights for TV streaming, offline downloads, multi-device access, and kids' profiles.
* **FAQ Section:** Interactive-style FAQ accordion blocks with custom hover state colors.
* **Footer Navigation:** Structured link hierarchy matching the real layout, complete with language selection.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic elements for structure.
* **CSS3:** Flexbox, CSS Grid, Custom Variables, Media Queries, and Font imports.
* **Font Awesome (v7):** Icons for interactive UI elements.
* **Google Fonts:** *Poppins* and *Martel Sans*.
